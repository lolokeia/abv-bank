# Общая информация
**ABV-BANK - Учебный проект по созданию клиент-серверной системы банка с использованием сетевых технологий.**
Проект создан в рамках индивидуальной/курсовой работы в колледже.

## Стек:
* Python 3.13/14
* customtkinter
* SQLite
* bcrypt
* json
 


## Основные функции:
* TCP запросы с фреймингом через socket
* токенизация - UUID пользователя не может попасть к пользователю. срок годности токена по умолчанию - 5 минут.

* **Клиент**
  * окно логина/регистрации
  * главное меню со счетами пользователя
  * меню настроек
  * окно отдельного выбранного счета с операциями над ним
  * окно ошибок
  * окно коннекта к серверу
  * Отправка на сервер и ожидание ответа в отдельном потоке
    
* **Сервер**
  * обработка клиентов в отдельном потоке
  * консоль для ведения администрирования
  * логирование в latest.log
  * невозможность SQL-иньекции
  * хеширование пин-кода на сервере
  * проверка написания номера счета с помощью чек-суммы

## Установка и запуск
### Windows
1. Скачайте последний релиз с github.
  * сервер
  2. настройте сервер через config.py
  3. Запустите server_main.bat для сервера
  * Клиент
  4. Настройте клиент через client_config.py (ip по умолчанию: 127.0.0.1)
  5. Запустите ярлык client.lnk
### Linux headless:
1. скачайте релиз: ```bash```
