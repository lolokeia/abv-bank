# Architecture:

## Modules:

### Server
**db.py** - низкоуровневый модуль для обращения к базе данных.
Формат запроса: db.get_bal(uuid)
Формат ответа: Значение или словарь

**auth.py** - высокоуровневый модуль авторизации
Формат запроса: auth.login(login, 1234)
Формат ответа: Словарь ответа

**transactions.py** - высокоуровневый модуль обработки транзакций
Формат запроса: transactions.deposit(uuid, 900)
Формат ответа: Словарь ответа

### Shared

**comms.py** - формат запросов и ответов

request("action", {"data": 123}) - запрос. обычно для общения "клиент > сервер"
error("message") - сообщение об ошибке, обычно для общения "сервер > клиент"
ok("message", {"data": 123}) - сообщение успеха, обычно для общения "сервер > клиент"

**protocol** - штука для перевода словаря json в байты для последующей отправки

## Server & client

**Server.py** - Собирает все вместе:
* поднимает сервер на порте
* обрабатывает подключение
* обращается к базе данных
* Обрабатывает транзакции
* возвращает ответ

**Client.py** - тоже собирает все вместе:
* Подключается к серверу
* получает нужную инфу с сервера
* посылает запросы на транзакции
* обновляет баланс
* хранит токен сессии

## пример

### login:
* Клиент просит данные у пользователя (ввод login и pin_input)
* Клиент отправляет request на сервер аля {Логин, {логин: abv_bank, пин: 1234}}, сначала эапрос на дейтвие - логин, затем данные от пользователя.
* Сервер принимает запрос и обрабатывает логин через auth.py - в данном случае все норм.
* сервер проверяет, если ли пользователь с логином "abv_bank" - есть
* сервер проверяет, правильный ли пин ввел пользователь - да
* сервер возвращает на клиент ok({"доброе утро, Илья", balance: 1000, uuid: uuid})
* клиент принял ответ от сервера
* клиент пишет пользователю, что он успешно вошел, и что у него 1000 рублей.

### withdraw
* клиент отправляет request на сервер (uuid - это сессия, и amount - сколько вывести)
* сервер принимает
* сервер запускает команду transactions.withdraw()
* она проверяет, есть ли сумма на балансе, и кратна ли она 100. - в нашем случае да
* функция списывает с баланса 1000 рублей и оставляет транзакцию в список транзакций
* сервер отправляет на клиент ответ: успех, теперь на балансе 0 рублей.
* клиент выставляет свой баланс в соответствии с сервером.

### Объяснение

* Клиент не знает баланс. его ему говорит сервер. клиент просто показывает его. даже если поменять баланс через cheat engine например, то он изменится только на клиенте.
* Клиент посылает запрос
* Клиент не проводит вычисления
* клиенту не прихродит пин-код в открытом виде. он вообще не прихордит. хеширование тоже на стороне сервера
