# Architecture:

## Modules:

### Server
**db.py** - низкоуровневый модуль для обращения к базе данных.
Формат запроса: db.get_bal(uuid)
Формат ответа: Значение или словарь

**auth.py** - высокоуровневый модуль авторизации
Формат запроса: auth.login(login, 1234)
Формат ответа: Словарь ответа

**transactions.py** - высокоуровневый модуль обработки транзакций
Формат запроса: transactions.deposit(uuid, 900)
Формат ответа: Словарь ответа

### Shared

**comms.py** - формат запросов и ответов

request("action", {"data": 123}) - запрос. обычно для общения "клиент > сервер"
error("message") - сообщение об ошибке, обычно для общения "сервер > клиент"
ok("message", {"data": 123}) - сообщение успеха, обычно для общения "сервер > клиент"

**protocol** - штука для перевода словаря json в байты для последующей отправки

## Server & client

**Server.py** - Собирает все вместе:
* поднимает сервер на порте
* обрабатывает подключение
* обращается к базе данных
* Обрабатывает транзакции
* возвращает ответ

**Client.py** - тоже собирает все вместе:
* Подключается к серверу
* получает нужную инфу с сервера
* посылает запросы на транзакции
* обновляет баланс
* хранит токен сессии
