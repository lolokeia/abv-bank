## Этап 3. Перестройка архитектуры БД под счета (`Accounts`)
- [ ] **Модификация таблиц в `db.py`**
  - Полностью удалить поле `balance` из таблицы `Users`.
  - Создать новую таблицу `Accounts` со следующими полями:
    - `account_uuid` (TEXT PRIMARY KEY) — внутренний ID счета/карты.
    - `user_uuid` (TEXT NOT NULL, FOREIGN KEY) — привязка к владельцу с `ON DELETE CASCADE`.
    - `account_name` (TEXT NOT NULL) — кастомное имя («Основной», «Заначка»).
    - `currency` (TEXT NOT NULL) — код валюты в верхнем регистре (`RUB`, `USD`, `EUR`).
    - `balance` (INTEGER DEFAULT 0) — баланс строго в копейках/центах.
    - `created_at` (TIMESTAMP) — системное время открытия счета.
- [ ] **Обновление вспомогательных функций БД**
  - Переписать функцию `update_bal` ➔ `update_account_bal(account_uuid, new_bal)`.
  - Написать функцию `create_account(user_uuid, account_name, currency)`.
  - Написать функцию `get_user_accounts(user_uuid)` для выгрузки всех карт пользователя.
- [ ] **Автоматическое создание дефолтной карты**
  - В функции `auth.register()` сразу после создания записи пользователя вызывать `db.create_account()` для автоматического открытия первого рублевого счета с именем «Основной» и балансом `0`.
